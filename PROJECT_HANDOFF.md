## Product direction
Read `MASTER_PLAN.md` before development. Nhân Sinh Lộ is a systemic choice-driven Life Roguelite. Occupations are contexts, not classes. Systems and consequences must cross-pollinate.

## NON-NEGOTIABLE TEST GATE
After each meaningful version/checkpoint:
1. finish only that checkpoint;
2. build/test;
3. commit/push main;
4. deploy GitHub Pages;
5. report version + test URL + test checklist to user;
6. STOP;
7. continue only after explicit user approval.

If user reports a bug, remain on the current checkpoint until the redeployed build is approved. Never continue several untested versions in sequence.
